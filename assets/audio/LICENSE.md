# assets/audio ライセンス表記

本ディレクトリ (`assets/audio/`) に同梱されている音源ファイルは、すべて本リポジトリ内で
合成（プログラムによる波形生成）した原著作物であり、第三者が著作権を持つ素材・録音・
サンプルライブラリ等を一切含みません。CC0 素材やフリー音源サイトからダウンロードした
ファイルも使用していません。

これらの音源ファイルのライセンスは、本リポジトリ本体と同一のライセンスに従います。

## ファイル一覧

| ファイル名 | 生成元 | 内容 |
| --- | --- | --- |
| `alarm.wav` | 既存（本リポジトリのために合成） | bell 系の単純なビープ音 |
| `buzzer.wav` | `tool/synth_sounds.dart` が生成 | 220Hz 矩形波を 0.25秒ON/0.15秒OFFでゲートした、耳障りなブザー音（約2秒） |
| `chime.wav` | `tool/synth_sounds.dart` が生成 | 880/1320/1760Hz の正弦波パーシャルを指数減衰させて重ねた、ベルのような穏やかなチャイム音（約3秒） |
| `siren.wav` | `tool/synth_sounds.dart` が生成 | 約600Hz〜1200Hzの間を上下にスイープする正弦波のサイレン音（約2秒） |
| `birds.wav` | `tool/synth_sounds.dart` が生成 | 約2.5〜4kHzの帯域を短くスイープする、鳥のさえずりを模した柔らかいチャープ音（無音区間を挟みながら約3秒） |

## 再生成方法

`buzzer.wav` / `chime.wav` / `siren.wav` / `birds.wav` はすべて、以下のコマンドで
リポジトリルートから再生成できます。乱数を使用しない決定論的な合成のため、
再実行しても常にバイト単位で同一のファイルが生成されます（再現性・監査可能性のため）。

```
dart run tool/synth_sounds.dart
```

## 備考

- いずれのファイルもループ再生（アラームプラグインによるループ）を前提として、
  波形の先頭・末尾が振幅ゼロになるように、かつパターン周期の整数倍の長さになるように
  設計されており、ループの継ぎ目でクリック音が発生しません。
- 各音のバースト部分には約5msのフェードイン/アウトを適用しており、内部的な
  エッジノイズも発生しません。
- ピーク振幅はフルスケールの約0.6に抑えており、クリッピングは発生しません。
